### 🧠 Notable Repositories

- 🔥 [FHIRcracker](https://github.com/meep-morp/FHIRcracker)  
  NestJS service that processes FHIR bundles and generates readable summaries using NVIDIA’s NeMo Retriever OCR AI. Built for healthcare teams who need fast, human-friendly insights from structured patient data.

- 🧪 [Extractify](https://github.com/meep-morp/Extractify)  
  A tool for parsing messy medical PDFs into structured data. Great for prototyping ingestion workflows and testing OCR pipelines.
